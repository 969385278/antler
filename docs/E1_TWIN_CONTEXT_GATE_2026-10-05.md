## 固定材料和范围

`data/diagnostics/twin_outcome_dev_v1.json`包含六个情境，O/E/A各两个。每情境两种相反的行动分别配好/坏结局，形成四段经历，共24段。比较同一行动下的结局双胞胎，再检验反馈的影响是否随行动方向反转。

材料SHA256：`04a160c4c41c0ea9ebb7e97d61b7071136ab51a9b9c3b2c0ac7dcd17bea4e5cb`。两个行动均共享同样结局，不能用好反馈直接代替人格正方向。

作者建议的“结果×行动”在本轮只作为方向假设，不用于生成δ或训练标签。故事由助手起草，未经过独立模型方向标注，不计入D1配额、正式D2或独立test。C/N及其他维度不从本轮外推。

同情境前缀逐字相同，两种行动共享相同结局文本；故事不含“从此我会/我学会了”等未来行为结论。六个情境是设计单位，2520条回答不是2520段独立经历。花园和俱乐部房间的结构相似，因此也不能把六情境当充分的跨家族泛化证据。

- 三项评分最多7560项；同输入缓存复用不算独立评分，也不追加调用。各维各极把全部条件合并seed0乱序，单线程单次请求，评委不接收故事、行动/结局标签或臂名。

- 全部条件仅有离散上下文，无Steer注入、无可学习参数、无MMLU调用。

## 主要量：行动敏感的结果效应

在每个情境、每个极点上，先按题平均三个种子。令T(a,r)为行动a∈{−1,+1}、反馈r∈{−1,+1}的人格分。

```
D_plus  = T(+1,+1) − T(+1,−1)
D_minus = T(−1,+1) − T(−1,−1)
I = (D_plus − D_minus) / 2
V = (D_plus + D_minus) / 2
```

I是行动敏感的反馈交互，V是两种行动共享的反馈变化。高极按原分数，低极将I/V反号，仅统一方向比较；高低两套题不合成一个人格分。若只有V而I未建立，不能宣称结果按行动意义写成人格更新。

按题配对bootstrap（10000次、seed0），同一次重采样用于四个单元、两种行动和三项指标。每情境各极分别报告D_plus/D_minus、I/V点估计与95%题目区间，保留原始方向与统一方向版本。区间仅覆盖十道题，不覆盖独立情境泛化；不作多重比较后的正式发现声明。

每故事还报告相对五中性平均及无记忆对照的三项绝对分、差值和区间；质量指标不随低极反号。报告全四单元，不按方向命中筛掉故事。按种子列出I/V，不用合并均值掩盖种子差异。

## 闸门与停止

本轮为机制开发闸门，以下分类不是E0 Strict/Practical或E1通过线：

- 每极I的区间下限>0：该极“预期交互有证据”；上限<0：该极“反向交互”；其余“未建立”，缺分则“不完整”。
- 情境两极均有预期交互证据，才标为本批“上下文结果效应已建立”；仅一极有证据标为“部分证据”，完整两极但均未建立标为“未建立”。任一极反向单独明确报告。
- 不完整、部分、反向和未建立均保留，不追加种子、故事、长回答或新评分来过线。
- 全部六情境一次完成即停，接口/文件/模型异常停止并保留已生成与已评分证据，不自动重启。同一固定计划仅允许一个执行claim。
- 截断比例及各单元质量分随结果同时报告；上下文交互成立不自动授予任何注入方向、幅度的行为资格，能力≤2pp和后续质量/test要求保留。

本批若未建立目标效应，先报告具体材料、模型和测量下的结果，不启动针对失败情境的压缩来弥补，也不推断所有记忆格式均不可行。下一步写入格式、幅度、中心、错配规则和预算须另行锁定。
