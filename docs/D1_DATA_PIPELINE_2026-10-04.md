# C10：D1数据准备与独立标签合并

> 最新接口状态：作者随后指定MiniMax/GLM并提供凭据，MiniMax-M3与glm-5直连接口均已通过最小调用检查。下方仅DeepSeek网关的盘点是历史记录，不再构成接口配置依赖。详见`D1_ANNOTATION_2026-10-04.md`；正式经历标注仍待执行。

依据规格§5.3准备正式D1，目标仍为200单维、40中性、40多维。此工具不将旧pilot或合成测试数据包装为正式经历，也不调用主评委替代独立标签。

候选必须附id、text、intended、generator和generator_vendor。检查40–80英文词、第一人称、固定禁词、唯一文本/id、合法O/C/E/A/N正负标签，以及生成厂商与主评委不同。禁词表包含人格维度名称和常见两极词形，随运行归档。词数和第一人称检查不能证明故事具有请求→行动→反馈→结果结构，这部分仍需语义审核。

盲标导出只含随机化后的新id与text。预期标签、生成模型与原id映射分开保存，不随盲标文件发送。两个标注模型必须身份不同且厂商均不是主评委DeepSeek；标签文件声明model、vendor、input_sha256、records（每条含id和labels）。模型身份声明只能作为来源记录，真实API请求/响应仍需上游另行归档，工具本身不能证明盲标独立性。

合并要求完整覆盖、输入哈希与原映射相符；两个模型标签均与预期完全相同才保留。不同意见原样保存，缺额或超额不抽取有利样本凑配额。每个单维正负格各20、中性/多维各40全部满足才分层固定划分60/20/20；中性和多维各作为一个层，多维逐维正负分布仍须后续检查，不能凭粗分层宣告全部维度在各split平衡。关联经历入口拒绝切分，需另行按语义家族分组，防止改写跨集泄漏。

逐维报告包含未标注影响（0）的两模型一致率和Cohen's kappa，并附各类数量，避免把大量0的一致解释成方向识别能力。无论配额是否满足，formal_ready保持false：60段盲审、语义结构检查、多维切分平衡与真实独立标注证据尚需完成。本工具不修改规格里的人工标注要求。

准备：`python scripts/build_episodes.py --config configs/main.yaml --candidates <候选.jsonl>`。

合并：在同一命令上加`--prepared <准备输出目录> --labels-a <标签A.json> --labels-b <标签B.json>`。产物写配置输出路径的唯一目录，保留输入/产物哈希、失败记录和所有标签分歧。
