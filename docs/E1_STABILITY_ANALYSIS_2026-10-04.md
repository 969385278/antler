# C11：δ 探针重复测量的分析组件

## 目的与现状

E1 的“稳定压缩”不能用 A/B 余弦代替：B 从 A 初始化，两者相似不等于换一组探针后仍得到相似坐标。新增 `antler/eval/e1_stability.py` 仅提供真实重复测量的配对描述统计，目前没有相应真实重复测量结果，不能宣告稳定。

本组件不启动 GPU 实验，不改变运行中的 dev 网格，不代替规格 9.6 的层、探针数及其他消融，也不修改 9.7 的正式通过条件。重复测量的具体输入清单、探针、超参数和请求预算仍须在实际运行前登记。

## 比较要求

- 同一方法分别比较：A 对 A，B 对 B；固定层、坐标基及单位 `s_layer`。
- `fit_settings` 必须一致；B 采集端需完整记录学习率、步数、正则、初始化规则、种子和注入阶段，A 记录读出与基线规则。该字段相等不能替代源配置审计。
- 两组探针等量、组内去重、组间互不重叠；只用 `trait_extract`，不能引入 `trait_eval`。
- 全部经历逐条配对，原文哈希、家族和预先指定目标一致；不丢失表现差的经历，不用换文本制造重复测量。
- 坐标固定 O/C/E/A/N 顺序，拒绝缺维、非有限数值及重复身份。

## 报告内容

逐经历报告五维余弦、两次范数、范数比、相对 L2 变化和坐标符号一致率。相对 L2 定义为 `||δ_repeat − δ_reference|| / ||δ_reference||`。零参考范数时，范数比和相对 L2 未定义；任一向量为零时余弦未定义，必须保留数量。

按预定目标维度同时报告“符号一致”及“两次都与预期一致”的计数。两次都错也可能很一致，不能只报一致率。附带维度不追认为新的目标。

报告经历数和家族数；同家族样本不可当独立重复。本组件不计算忽略家族的显著性，不添加事后稳定性通过线，`formal_e1_pass` 恒为 false。坐标稳定性证据仍需与语义正确性、KL 对照和后续行为验证合起来评估。

## 工程验证范围

单元测试覆盖同方向不同幅度、稳定但方向错误、零向量、不同配置、重复探针、缺失经历、原文变化及非有限坐标。这些测试只证明统计组件按定义工作，不产生真实稳定性证据。
